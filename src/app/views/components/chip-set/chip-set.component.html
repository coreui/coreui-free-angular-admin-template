Angular Chip Set Basic chip set

Group multiple chips inside c-chip-set and pass them through the chips input. Once the chips are selectable or removable, the set gives them a single tab stop with arrow-key navigation.

Angular Chip Set Selectable chips

Set selectable on c-chip-set to make every chip in the set selectable. With the default selectionMode of "multiple", any number of chips can be active at once — useful for filters.

Use selectionMode="single" to allow only one selected chip at a time — selecting a chip deselects its siblings. This is useful for choice chips.

Angular Chip Set Filter chips

Add filter to turn the chips into filter chips. A check icon is shown on each selected chip and removed when it is deselected. filter implies selectable, so you don't need to set both.

Angular Chip Set Removable chips

Set removable to add a remove button to every chip. When a chip is removed, focus moves to a neighboring chip. Bind [(chips)] to let the chip set remove chips from your list.
