Angular Chip Input Basic example

Chip input lets users enter multiple values in one field. Use the c-chip-input component with inputs like placeholder and value.

Angular Chip Input Variants

Use the chipClassName input to apply contextual chip styles, which is handy for labels, issue types, or priorities.

Angular Chip Input Sizes

Use the size input with "sm" or "lg" to align the field with surrounding form controls.

Angular Chip Input Empty state and label

You can start with an empty field or use a separate cLabel for clearer form structure and accessibility.

Press Enter or comma to add a value.
 Angular Chip Input Disabled and readonly

Use the disabled input to block interaction entirely, or readonly to keep values visible while preventing changes.
